Tres herramientas que se ejecutan en un comando

Funcionan con Node.js 20 o superior y sin instalar dependencias. Reciben la carpeta de un proyecto y escriben el resultado en la terminal.

secret-audit

Busca un .env subido a Git, claves y contraseñas en el código y logs que imprimen tokens.

Nunca muestra el valor completo de un secreto.

$ npm run audit -- ../mi-proyecto

api-docs

Lee un backend Express y arma la tabla de endpoints: método, ruta, si exige autenticación y qué campos recibe.

$ npm run api -- ../mi-proyecto/backend

readme-gen

Genera un README en español con tecnologías, estructura, instalación, variables de entorno y API.

$ npm run readme -- ../mi-proyecto

Un agente que hace el trabajo desde Telegram

Escríbele la dirección de un repositorio público de GitHub y te responde con el reporte. También te avisa cuando llega una reseña nueva a ReviewHub.

  • /auditar busca secretos expuestos en el repo.
  • /api documenta los endpoints.
  • /readme genera un README.
  • /resenas resume las reseñas: cantidad, promedio y las más recientes.

Solo responde a los chats que tú autorices y solo acepta direcciones de GitHub. Cómo ponerlo en marcha.

/auditar https://github.com/luamesa/FINALDW
